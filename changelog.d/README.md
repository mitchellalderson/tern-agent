# Changelog fragments

One file per change: `<slug>.<kind>.md`. Kind: `added`, `changed`, `deprecated`, `removed`, `fixed` or `security`.
The body is the bullet(s), written as they should appear. Don't edit `CHANGELOG.md`; the release gathers these.

Example, `changelog.d/memory-section.added.md`: `- **Memory section** in the agent sheet.`
