# v0.1.0-alpha.8

**Released 2026-11-18** as a pre-release: [v0.1.0-alpha.8](https://github.com/mitchellalderson/tern-agent/releases/tag/v0.1.0-alpha.8),
tagged on `12451e8`.

tern is now **local-only and single-player**, **local models first** (Ollama), with the learnings from innbot applied
(`docs/innbot-learnings.md`).

## Release checks

- The release workflow passed: CI, four CLI builds, the desktop app, publish. 13 files.
- The Apple Silicon CLI tarball: checksum matches, `gh attestation verify` passes, it reports `tern 0.1.0-alpha.8`.
- The DMG is ad-hoc signed, not notarized: the first open needs **Open Anyway** in System Settings.
