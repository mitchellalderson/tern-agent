## Check first after tagging

- **First run on a clean Mac** (checklist section 5): "Set up with Ollama" with and without Ollama installed, and
  "Use an API model instead". Nothing here has run against a real Ollama install outside tests.

  `secrets.toml` migrates to encrypted; old `deliver_to` gateway values move to Home.
- **Keychain:** the secrets key is read without a prompt; with no keychain, `secrets.key` is used.
