## Release

- Tagged `v0.1.0-alpha.2` on `f109191`. Every `release.yml` job passed, including macOS (about 9 min after #21).
- https://github.com/mitchellalderson/tern-agent/releases/tag/v0.1.0-alpha.2 is a pre-release with 13 assets: 4
  tarballs, the DMG and zip, a `.sha256` for each, and `SHA256SUMS`.
- `tern-aarch64-apple-darwin.tar.gz`: the checksum matches, `gh attestation verify` passes, and `tern --version`
  prints `0.1.0-alpha.2`.
- Not done: the clean-machine smoke tests (`docs/release-checklist.md` §5). The owner runs these on the DMG.

## Carried over to alpha.3

- **PR #24:** two flaky-test fixes, sandbox `ETXTBSY` and a `delegation` pointer race. Open.
- **Quarantined sub-agents** (design in #4). Files carry no provenance, so since #13 a tainted run can write
  workspace files that a later clean run trusts.
- **"Allow edits to this file for this run"** grant for writes outside the workspace in tainted runs. Offered, not
  decided.
- **Screenshot Dart tests:** 9 files, about 3,400 lines, flagged by the audit for review.
- **`wait_until` follow-ups** from #17: connector watches as a check, authenticated URLs, a live push event, and a USD
  cap for continuations.
- **Missing doc:** `docs/alpha-workspaces.md` is referenced by the fetch design but doesn't exist.
